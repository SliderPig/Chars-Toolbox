# Char's Toolbox

## Description

One file with fourteen handy tools. Each has its own on/off switch, so you keep only what you want, and switches work right away.

- Y, /toolbox, the Mods list or the small cat on the pause screen opens the switch screen
- Map: a minimap and a world map with waypoints
- Far View: see land far past your render distance
- Main Menu: a cherry blossom title screen
- Teams, Config Helper and Fortress Boxes
- Bring my settings: your keys, options, server list and switches follow you into a new profile
- Key clash fixer: finds keys that do two things and moves one, with undo
- Zoom (hold H), Little HUD, Pickup list, Gear watch and Memory watch
- Cat corner: a sleepy black cat on your screen, plus Fullbright, Auto Rejoin and Auto Eat, which stay off until you switch them on

Works on any server: everything runs on your own PC. Teams, Config Helper and Fortress Boxes have a server half too, which joins in when the server has them. Some parts are also separate mods; if a separate copy is in your mods folder, that copy runs and its row says so.

Early version: if something goes wrong, please say so in the comments.
